# Computer Graphics and Multimedia System Lab

This repository contains a folder-wise collection of Python programs for computer graphics and multimedia systems. Each laboratory program is stored as a numbered `.py` file.

## Course roadmap

| Folder | Topics |
|---|---|
| `basic_graphics/` | Drawing primitives, line generation, circle generation |
| `transformations/` | 2D translation, rotation, scaling, reflection |
| `clipping_and_viewing/` | Line clipping and window-to-viewport mapping |
| `curves_and_fractals/` | Bezier curves, Hermite curves, fractal patterns |
| `multimedia_processing/` | Image operations, color models, audio waveform visualization |
